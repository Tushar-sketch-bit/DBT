# Coding Conventions & Project Constraints

## System Execution Principles (Ponytail Workflow)
- **Extreme Minimization:** Do not install external packages unless explicitly instructed. Always prioritize standard library packages or already-installed project dependencies first.
- **No Over-Engineering:** Avoid creating boilerplate utility configurations or extra structural helper files that were not directly requested.
- **Refactoring Guardrails:** Before generating structural file refactors, audit for minimal code footprints. Delete dead loops or redundant blocks immediately.
- **Explicit Execution:** Always prioritize simple, idiomatic language syntax instead of complex generic abstractions.
